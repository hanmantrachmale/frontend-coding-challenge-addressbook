# Engineering Constitution

Every code contribution must satisfy:

## Security

- No secrets in source code.
- Input validation required.
- Output encoding required.

## Reliability

- CancellationToken required.
- Error handling required.
- Structured logging required.

## Maintainability

- Follow Clean Architecture.
- Follow SOLID.
- Follow DRY.

## Testing

- Unit tests required.
- Integration tests required for APIs.

## Observability

- OpenTelemetry supported.
- Correlation IDs supported.
